# Little Moments — 飞书照片墙起步模板

这是一个纯静态网页模板，包含：
- Pinterest 风格的瀑布流照片墙
- 点击图片查看大图
- 全屏自动轮播（每 4 秒切换）
- 随机排序
- 手机/电脑自适应布局

当前 `photos.js` 中是示例图片，尚未连接飞书自动同步。

## 1. 先本地预览
直接双击 `index.html` 通常即可预览。若浏览器限制本地文件访问，可在该文件夹启动一个本地静态服务器，或直接部署到 GitHub Pages。

## 2. 替换图片
编辑 `photos.js`，按以下格式添加或替换条目：

```js
{
  src: "https://example.com/your-image.jpg",
  title: "照片标题",
  location: "地点 · 日期",
  alt: "图片的简短描述"
}
```

图片地址必须能在未登录状态下直接访问。请只上传自己有权公开展示的图片。不要把飞书私有链接、登录令牌、身份证件或私人截图放到公开网页。

## 3. 发布成公开网址（GitHub Pages）
1. 登录 GitHub 并创建一个新的 **Public** repository，例如 `little-moments-wall`。
2. 将本文件夹里的 5 个文件上传到仓库根目录：`index.html`、`style.css`、`photos.js`、`app.js`、`README.md`。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**。
6. 等待部署完成。GitHub Pages 会显示一个公开网址，通常形如 `https://你的用户名.github.io/little-moments-wall/`。

注意：仓库是公开的，任何人都可以看到仓库内的代码和 `photos.js`。不要在其中放私人信息或密钥。

## 4. 后续实现飞书自动同步（第二阶段）
目前网页不会自动读取飞书。要可靠地同步，需要进一步搭建一个同步流程：
1. 在飞书开放平台创建应用，并申请读取目标文档/文件所需的最小权限。
2. 明确图片所在位置（文档内嵌图片、云空间文件，还是聊天记录）。不同来源的 API 和权限不同。
3. 使用安全的服务端任务获取图片并同步到图片存储服务。
4. 自动更新照片清单或图库数据。
5. 把密钥保存在服务端环境变量中，**不要**放进静态网页或公开 GitHub 仓库。
6. 设定同步频率，并处理失效链接、删除照片、重复照片及公开访问权限。

**重要：** 飞书文档中的图片并不一定有长期有效的公开直链。为了让“别人不用登录飞书也能打开照片墙”，通常需要把获准公开的图片同步到可公开访问的图片存储中。公开网址意味着图片可能被任何人查看或保存。

## 推荐的下一步
先把这个模板部署起来确认视觉效果。之后再根据你的飞书图片具体存储位置，设计自动同步；不要在还没确认权限和来源之前就批量公开图片。
